👨‍👩‍👧 Set up Family Sync

One-time, about 5 minutes. This lets relatives in other homes trade stickers with you. Free — it uses your own Google Sheet.

1 · Make a Google Sheet

It will quietly store who has which stickers.

Create a blank Sheet ↗

2 · Add the script

In your Sheet: Extensions → Apps Script. Delete anything there, then paste this and click Save:

Loading…

3 · Publish it

Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone, then Deploy. Copy the /exec URL it gives you.

4 · Make your family link

⚠️ You're running this on your own computer, so this link starts with localhost and won't open on your family's phones. Make the link from the hosted site instead: github.io setup page.

✉️ Email it

🔒 This link is built right here in your browser — the URL and code aren't sent anywhere. Anyone with the link can see and edit your family's stickers, so only share it with family.

Paste your /exec URL and a code above to get your link + QR.
