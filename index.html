💻 Run it on your computer

No server skills needed. Works on Mac, Windows & Linux — uses Python or Node if you already have them.

  1. Download the project: the green Code → Download ZIP button on GitHub, then unzip it.
  2. Double-click the launcher for your computer: start.command (Mac), start.bat (Windows), or start.sh (Linux).
  3. Your browser opens the Hub at http://localhost:8080/worldcup/. That's it!

Prefer Docker? docker build -t worldcup . && docker run -p 8080:8080 worldcup, then open localhost:8080/worldcup/. Full notes are in the README.
